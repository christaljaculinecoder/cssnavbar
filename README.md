
# Task — Navigation Bar Using HTML and CSS

## Objective

**Create a navigation bar using HTML and CSS.**

The goal is to demonstrate the use of Flexbox, navigation links, buttons, spacing, alignment, and styling to create a simple navigation bar.

---

## Task Description

Create a navigation bar using HTML and CSS with the following elements:

- **Logo:** Display a logo on the left side of the navigation bar.
- **Navigation Links:** Include Home, About, and Contact links.
- **Login Button:** Display a Login button on the right side of the navigation bar.

The navigation bar should have a black background, white text, and an orange Login button.

---

## Requirements

1. Create an HTML file with the basic HTML5 document structure.
2. Set the document language to English using `lang="en"`.
3. Include the character encoding using `<meta charset="UTF-8">`.
4. Include the viewport meta tag for responsive viewport configuration.
5. Link the external CSS file named `style.css` using the `<link>` tag.
6. Create a navigation bar using the `<nav>` element with the class `navbar`.
7. Add a Logo using a `<div>` element with the class `logo`.
8. Create navigation links using an unordered list (`<ul>`) with the class `nav-link`.
9. Include the following navigation links:
   - Home
   - About
   - Contact
10. Add a Login button using the `<button>` element with the class `btn`.
11. Use Flexbox to align the logo, navigation links, and Login button horizontally.
12. Use `justify-content: space-between` to distribute the navigation bar elements.
13. Use `align-items: center` to align the elements vertically.
14. Set the navigation bar background color to black and the text color to white.
15. Apply padding to the navigation bar using `padding: 15px 40px`.
16. Style the logo with a font size of `22px` and bold font weight.
17. Remove the default list markers using `list-style: none`.
18. Use Flexbox and `gap: 25px` to arrange the navigation links with spacing.
19. Remove the default underline from the navigation links using `text-decoration: none`.
20. Set the navigation link text color to white and font size to `16px`.
21. Style the Login button with `padding: 8px 16px`, an orange background, white text, and no border.
22. Use `cursor: pointer` to display a pointer cursor when hovering over the Login button.
23. Apply a universal selector (`*`) to reset the default margin and padding, set `box-sizing: border-box`, and apply the specified font family.
